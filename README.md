# 📊 NIPUN Maharashtra — Learning Outcomes Analytics Dashboard

> **An interactive Power BI dashboard designed to monitor student assessments, learning outcomes, and performance across schools, blocks, districts, standards, and subjects in Maharashtra.**

---

## 🎯 Project Overview

The NIPUN Maharashtra Learning Outcomes Dashboard transforms assessment data into an interactive analytical solution for monitoring student performance and learning outcomes.

The dashboard provides stakeholders with a centralized view of assessment coverage and performance, enabling analysis across different geographic, academic, and administrative dimensions.

It helps users move from a **state-level overview to district, block, and school-level analysis** to identify performance gaps and areas requiring attention.

---

## 💼 Business Problem

Large-scale education programs generate data across multiple levels — students, schools, blocks, districts, standards, subjects, and learning levels.

Without an interactive analytical view, identifying performance patterns and areas requiring intervention can be time-consuming.

This dashboard was developed to:

- Monitor student assessment coverage
- Analyze learning outcomes across subjects and standards
- Compare performance across districts and blocks
- Examine school-level performance
- Understand learning-level distribution
- Identify areas with comparatively lower performance
- Support data-driven monitoring and decision-making
